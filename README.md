# Бар Коктейль — сайт-витрина

Сайт-витрина для бара «Коктейль», Ярославль, ул. Кирова 5/23. Работает с 1996 года.

## Стек

- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS v4** (конфиг в `globals.css`)
- **GSAP 3** (ScrollTrigger, timeline анимации)
- **Phosphor Icons**
- **pnpm**

## Запуск локально

```bash
pnpm install
pnpm dev        # http://localhost:3003
```

```bash
pnpm build      # production build
pnpm typecheck  # TypeScript check
pnpm lint       # ESLint
```

## Страницы

| Маршрут | Описание |

| `/` | Главная: hero, факты, авторские коктейли, соцсети, бронирование |
| `/menu` | Меню: БАР и КУХНЯ, sticky навигация по категориям |

| `/promo` | Акции: счастливые часы, DJ-ночи и др. |
| `/reviews` | Отзывы: 4.9 на 2ГИС, ссылки на платформы |
| `/contacts` | Контакты и бронирование |

## Деплой на Vercel

1. Импортировать репозиторий на [vercel.com](https://vercel.com)
2. Framework Preset: **Next.js** (определяется автоматически)
3. Build Command: `pnpm build` (или оставить по умолчанию)
4. Install Command: `pnpm install`
5. Переменные окружения: не требуются для базовой версии

## Переменные окружения

Файла `.env` нет — сайт полностью статичен. При подключении Яндекс.Метрики добавить:

```
NEXT_PUBLIC_YM_ID=ваш_id_счётчика
```
